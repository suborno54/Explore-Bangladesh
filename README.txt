# Explore Bangladesh

A responsive travel website for exploring 27 tourist destinations across the eight divisions of Bangladesh.

Live demo: https://suborno54.github.io/Explore-Bangladesh/

## Features

- Search and filter places by division, district and type
- Photo gallery with a lightbox viewer
- Trip cost calculator
- Day-by-day itinerary planner with export and print
- Light and dark theme
- Works on desktop, tablet and mobile

## Built With

HTML, CSS and JavaScript

## How to Run

Download the files and open `index.html` in your browser.
